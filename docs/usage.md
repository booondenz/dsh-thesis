# 使用手册

> 只想知道怎么装：见 [README](../README.md)。这里讲**用起来是什么样**。

## 前置条件

- DSH 里装好 `dsh-thesis`，重启后可见 `thesis_*` / `fact_*` / `defense_code_*` 三组工具。
- **把会话开在论文目录里**最省事：多数工具从会话 cwd 向上探测 `00-管理/进度台账.md` 来定位工作区。
- 也可以显式指定：`config: { workspace: /path/to/你的论文 }`。配了它就**只认它**，路径写错会直接报错，
  绝不会写到别的目录去。

工作区可以是空的（还没有论文），`thesis_init` 会把九阶段目录、台账、决定日志、七章模板和技能包一次性建好。

## 第一次会话

把材料丢进工作区（或告诉它绝对路径），说一句：

```
这是我的论文材料，帮我做毕业设计
```

插件接管后是这样走的：

1. **弹一道选择题**（只有一次）：从零走到答辩 / 只补合规与答辩 / 只做答辩准备 / 先别自动跑。
   细节见 [autopilot.md](./autopilot.md)。
2. 选定后建目标、自动一轮轮跑：材料摄取 → 逐题追问 → 文献 → 设计 → 实现 → 测试 → 论文 → 合规 → 答辩。
3. 只在 **G1-G4 人工关卡**停下来，让你在审批界面点「允许」或「拒绝」。

没有材料也能用：「我要做毕业设计，还没定题」→ 走选题工作坊，先定课题再进流水线。

## 九阶段与关卡

| 阶段 | 产出物 | 验收标准 | 人工关卡 |
|---|---|---|---|
| 1 选题 | 选题确认书 | 课题明确、工作量合理、答辩友好 | **G1** |
| 2 开题 | 开题报告 + 任务书 | 导师认可；结构与规范达标 | **G3** |
| 3 文献调研 | 文献库 + 笔记 + 综述素材 | 15-30 篇真实文献；每篇有笔记 | — |
| 4 系统设计 | 需求/设计/选型文档 | 方案可落地；选型有论证 | — |
| 5 系统实现 | 可运行系统 + git 提交 | 功能真实可跑 | — |
| 6 系统测试 | 测试报告 + 真实结果 | 结果可复现；零伪造 | — |
| 7 论文撰写 | 七章正文 | 逐章人工验收 | **G2**（每章一次） |
| 8 定稿与合规 | 论文.docx + 检查报告 | 格式/引用/自查全部通过 | **G4** |
| 9 答辩 | 幻灯 + 演练记录 | 能讲清设计与实现 | — |

关卡由 `thesis_progress` 在工具层强制：未过该阶段的入口关卡时，任务推进会被**拒绝**（不是提醒）。

## 材料与追问

- `thesis_ingest <绝对路径>`：docx / xlsx / pptx / pdf / md / csv / bib，以及源码目录（只给文件、行数、
  声明与技术栈，**不贴源码正文**）。产出 `00-管理/材料清单.md` 与逐文件摘要；已存在的摘要绝不覆盖。
- `thesis_intake`：一次只问一个问题，每问都带「为什么问 / 影响哪个产出 / 合格答案形态」。
  材料里能读出来的不重复问；必答项不齐时拒绝 `done`。答案落盘成 `00-管理/意图规格.md`（唯一真相）。
- 断点续问：状态在 `.paper/intake.json`（相对工作区根），换会话接着问，不重复。

## 常见动作

| 想做的事 | 怎么说 / 调什么 |
|---|---|
| 换学校模板 | 把模板放进 `06-论文/assets/学校模板/`，再跑 `thesis_check`（探测到就用，探测不到显式标注「非学校模板」）|
| 只改某一章 | 直接说「改第三章的方法部分」，改完 `thesis_review 03-设计` |
| 回填学校查重结果 | `thesis_originality action=report detected_rate=12 detected_system=知网` |
| 出 Word | `thesis_build`（有 pandoc 用 pandoc + 模板，没有就用内置零依赖生成器）|
| 只做答辩 | `thesis_defense` → `thesis_slides` → 代码演练 `defense_code_*` |
| 记住学校规范 | `fact_remember key=school.dedup.system value="知网，查重阈值 20%"` |
| 看进度 | `thesis_progress action=report` |

## 产出物

| 产物 | 位置 |
|---|---|
| 意图规格（唯一真相） | `00-管理/意图规格.md` |
| 材料清单 + 逐文件摘要 | `00-管理/材料清单.md`、`00-管理/材料/*.md` |
| 进度台账 / 决定日志 / 时间线 | `00-管理/` |
| 文献库与检索审计 | `02-文献/refs.bib`、`检索记录.md`、`笔记/` |
| 章节与 Word | `06-论文/章节/*.md`、`06-论文/产出/论文.docx` |
| 答辩素材 / 幻灯 / 问题库 | `07-答辩/` |
| 检查报告（引用 / 格式 / AI 味 / 降重） | `08-合规/` |

## 中断与续跑

会话断了不要紧：进度、决定、追问状态、检索缓存全在工作区文件里。重开一个会话说一句
「接着做」即可——`thesis_progress action=report` 会把当前阶段、未过的关卡与下一步报出来。

## 多条流水线同时进行

一个工作区 = 一个课题。不同课题就不同目录，各开各的会话；跨会话的稳定事实（学校规范、
导师偏好）走 `fact_*`，那是全局共享的。
