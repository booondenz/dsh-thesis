# dsh-thesis

**把一堆材料变成一篇经得起查重与答辩的论文。**

[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 的单一插件。
给它学校模板、论文要求、实验数据、代码和参考文献，它先追问、再动手，按九个阶段推进：

**选题 → 开题 → 文献 → 设计 → 实现 → 测试 → 论文 → 合规 → 答辩**

纯 TypeScript，零运行时第三方依赖。对外只有三个命名空间：`thesis_*`、`fact_*`、`defense_code_*`。

## 安装

在 DSH 的**插件管理器里搜索 `dsh-thesis`**即可 装上。

从源码装：

```bash
git clone https://github.com/booondenz/dsh-thesis.git && cd dsh-thesis
npm install && npm run build
dsh plugin --profile web add "$PWD"
```

## 使用

把材料放进论文目录，或告诉它绝对路径，在**该目录下**开会话说：

```
这是我的论文材料，帮我做毕业设计
```

它会弹一道选择题（从零走到答辩 / 只补合规与答辩 / 只做答辩准备 / 先别自动跑），
选完就自动推进；撞上 G1-G4 关卡时在审批界面点允许或拒绝。

## 红线

- **零假文献**：引用只能来自真实检索缓存，`thesis_lit_save` 拒绝缓存外的 id。
- **零假数据**：数据与结果必须来自真实运行；降重不许改数据与结论。
- **人是作者**：G1-G4 关卡由工具强制，决定必须由你拍板。
- **规范以学校文件为准**：没有模板时用内置过渡模板并**显式标注「非学校模板」**。
- **降重不是洗稿**：不接收费查重，报告里是本地估算，与学校结果不可等同（可回填对照）。
- **不静默销毁数据**：读不出来 ≠ 不存在；读失败就抛错，绝不用默认值覆盖。
